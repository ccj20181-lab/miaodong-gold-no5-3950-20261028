# 黄金观察 NO.5 · v3 动效设计系统

> 原则：**高级感来自克制**。一套色、一套字、一套曲线；每屏只有一个视觉焦点。

## 1. 色板（深黑 + 香槟金）
| Token | 值 | 用途 |
|---|---|---|
| black | `#07080A` | 底色 |
| ink / panel | `#0E1013` / `#171A20` | 面板、图形底 |
| white | `#F6F1E7` | 暖白正文（不用纯白） |
| gold / goldHi / goldLo | `#E8C27A` / `#FFE3A3` / `#9C7A3C` | 唯一强调色；数字与关键词走三段金色渐变 + 柔光 |
| red | `#FF6B5A` | 只表示下跌/风险 |
| mint | `#5FD4B0` | 只表示支撑/现金/修复 |

## 2. 字体与字阶
- 标题：思源黑体 Heavy 72；栏目名 22（金）；场景标题 44
- 正文/标签：思源黑体 Bold 25–36；来源注释 19（72% 不透明）
- 数字：Barlow Semi Condensed，`tabular-nums`，滚动计数时不跳宽
- 字幕：统一思源黑体 Bold 48（替换原斜体得意黑），双层阴影，不加底框

## 3. 安全区（1080×1920）
- 顶部 220px、底部 380px 不放信息；右侧 140px 避开点赞栏
- 主窗沿用 v2：x48 y724 984×676，保证字幕/图形相对位置不变

## 4. 动效曲线与时长
- 入场 expo-out `cubic-bezier(.16,1,.3,1)`；转场/遮罩 `(.65,0,.35,1)`；出场 `(.7,0,.84,0)`
- 弹簧：soft（damping 200，无回弹，大面积）/ pop（damping 14，轻回弹，数字、柱子）
- 时长：入场 18f、遮罩 14f、逐字间隔 ≤1.6f、出场 8f、镜头转场 12f
- 同屏元素按 JSX 顺序自动错峰 4f

## 5. 组件
- **Text**：逐字上浮 + 透明度弹簧；可选关键词下划线（字后生长）
- **Num**：滚动计数（<100 从 0 起，价格从 96% 起）+ 0.86→1 弹簧放大 + 金色辉光
- **Line**：pathLength 描绘；虚线淡入
- **Head**：下三分之一式：金条生长 → 栏目名 → 标题逐字 → 发丝渐隐线
- **Foot**：来源注释延迟淡入，左侧金色短竖条
- **图表**：金线加宽光晕、面积渐变加深、当前点呼吸光圈
- **镜头**：Ken Burns 推拉交替 + 平移；背景同源虚化反向位移（视差）；统一调色
- **转场**：段内 zoom-blur；新段落交替 whip（甩镜+运动模糊）/ 斜切遮罩擦除；伴随一次漏光
- **质感**：胶片颗粒（15fps 更新，overlay 8%）、暗角、主窗内上下压暗渐层、金色角标与全片进度线
- **出场**：每个图形单元最后 8 帧淡出+轻模糊，不再硬切

## 6. 不变项
配音、BGM、字幕文本与时间点、标题、Logo、35 幕时间轴、所有数据与来源文字均与 v2 一致（stock_props.json 原样复制）。
